# Palliativ-Quiz

Quiz zur palliativen Versorgung im Pflegealltag, zum Üben und Wiederholen. Entstanden als Abschlussarbeit der Weiterbildung Palliative Care.

Quiz im Browser: https://chrispltv.github.io/palliativ-quiz/

Hinweis: Das Quiz ist eine Lernhilfe. Es ersetzt keine Behandlungsanweisung, keine ärztliche Anordnung und keine Rechtsberatung.

Das Quiz ist eine einzelne Datei (`index.html`). Es lädt nichts von Dritten nach und speichert den Lernstand nur im Browser der Nutzenden.
